## Week 12 – Lab 1: String Manipulation

**Total Points: 100**

## Learning Objectives

After completing this lab, students should be able to:

- Create and store a string in a variable.
- Accept string input from the user.
- Remove unnecessary spaces from a string.
- Determine the length of a string.
- Access individual characters using positive and negative indexes.
- Extract portions of a string using slicing.
- Convert strings to uppercase and lowercase.
- Replace content within a string.
- Split a string into a list of words.
- Use a loop to process words or characters.
- Display string-processing results clearly.
- Organize a program using a `main()` function.

## Assignment Overview

Create one Python program named `string_manipulation.py` that demonstrates several string-processing techniques.

The program will:

1. Ask the user to enter a sentence or phrase.
2. Store the entry in a string variable.
3. Remove unnecessary spaces from the beginning and end.
4. Display the first and last characters.
5. Display the length of the cleaned string.
6. Extract and display several substrings.
7. Convert the string to uppercase and lowercase.
8. Replace selected content.
9. Split the string into individual words.
10. Use a loop to process the words or characters.

The instructor is not providing completed Python code or an exact output design. Students must design, write, and test their own program.
